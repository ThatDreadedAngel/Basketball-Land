# Empire Basketball League

A browser-playable, original pixel-art basketball game prototype featuring all 16 custom teams and all 160 provided players.

## Play locally
Open `index.html` in a modern browser. The court is drawn immediately, and you can choose teams and start playing from the Play Game tab.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `game.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

## Controls
- WASD or arrow keys: move the controlled player
- Space: shoot
- P: pass
- S: attempt a steal
- Tab: switch controlled teammate
- On-screen buttons also work, including touch screens

This is an early playable prototype. The game includes roster browsing, a pixel court, simple movement, shooting, passing, steals, simulated possessions, game clock, scores and standings. Player movement and possession logic are intentionally lightweight for this first build.
